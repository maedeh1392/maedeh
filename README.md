# شطرنج آنلاین دونفره

یک بازی شطرنج ساده برای دو نفر با دو گوشی جداگانه.

## اجرا روی Render
- نوع سرویس: Web Service
- Build Command: `npm install`
- Start Command: `npm start`
- پورت توسط متغیر `PORT` تنظیم می‌شود.

پس از انتشار، بازیکن اول «ساخت اتاق جدید» را می‌زند و لینک را برای بازیکن دوم می‌فرستد. بازیکن دوم با همان لینک وارد می‌شود.

اتاق‌ها فعلاً در حافظه سرور نگهداری می‌شوند؛ با راه‌اندازی مجدد سرویس، بازی‌های درحال اجرا پاک می‌شوند.
